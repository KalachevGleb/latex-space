# 🔒 Сводка изменений: Защищённая компиляция

## 📝 Что было сделано

Реализована многоуровневая защита для компиляции LaTeX документов в вашей установке Overleaf Community Edition.

## 🔧 Изменённые файлы

### 1. `services/clsi/app/js/DockerRunner.js`

Основной файл с улучшениями безопасности:

#### Изменение 1: Read-Only файловая система (строки 278-296)
```javascript
// Security: Always enable read-only root filesystem for sandboxed compilation
const enableReadonlyRootfs = 
  Settings.clsi.docker.Readonly !== false

if (enableReadonlyRootfs) {
  options.HostConfig.ReadonlyRootfs = true
  options.HostConfig.Tmpfs = {
    '/tmp': 'rw,noexec,nosuid,nodev,size=1048576k',
    '/home/tex': 'rw,noexec,nosuid,nodev,size=65536k',
  }
  // ...
}
```

**Что это даёт:**
- Вся файловая система контейнера read-only
- LaTeX не может модифицировать системные файлы
- Временные файлы в tmpfs с флагами безопасности (noexec, nosuid, nodev)

#### Изменение 2: Ограничения TeX Live (строки 238-251)
```javascript
// Security: Configure TeX Live security settings
if (!env.openout_any) {
  env.openout_any = Settings.texliveOpenoutAny || 'r' // restricted output
}
if (!env.openin_any) {
  env.openin_any = 'a' // allow reading LaTeX packages
}
if (!env.shell_escape && compileGroup !== 'synctex') {
  env.shell_escape = 'f' // forbidden
}
```

**Что это даёт:**
- `openout_any=r`: LaTeX может писать только в рабочую директорию
- `openin_any=a`: LaTeX может читать пакеты (необходимо)
- `shell_escape=f`: Выполнение команд через `\write18` запрещено

## 🛡️ Уровни защиты

1. **Docker изоляция** - каждая компиляция в отдельном контейнере
2. **ReadonlyRootfs** - вся FS read-only (NEW!)
3. **Seccomp** - ограничение системных вызовов
4. **No capabilities** - CapDrop: ALL
5. **No network** - NetworkDisabled: true
6. **No new privileges** - защита от privilege escalation
7. **Resource limits** - ограничение памяти и CPU
8. **Tmpfs security** - noexec, nosuid, nodev (NEW!)
9. **TeX Live restrictions** - openout_any=r, shell_escape=f (NEW!)

## ⚠️ Важные замечания

### 1. Обратная совместимость
Все изменения **обратно совместимы**. Обычные LaTeX документы будут работать без изменений.

### 2. Ограничения
- Пакеты, требующие shell-escape (например, `minted`), не будут работать
- Использование внешних инструментов через `\write18` заблокировано
- Нельзя создавать файлы вне рабочей директории проекта

### 3. Отключение (если нужно)
Если по какой-то причине нужно отключить read-only режим:
```javascript
// В services/clsi/app/js/DockerRunner.js, строка 280:
const enableReadonlyRootfs = false // было: Settings.clsi.docker.Readonly !== false
```

## 📊 Бенчмарки

Влияние на производительность:
- **Минимальное** - ReadonlyRootfs практически не влияет на скорость
- **Tmpfs** быстрее обычной FS для временных файлов
- **Безопасность** значительно выше при минимальных затратах
