## 📝 КАК ИСПОЛЬЗОВАТЬ:

### 1. Добавить комментарий:

1. **Выделите текст** в редакторе
2. Появится **всплывающее меню**
3. Нажмите **"Add comment"** или иконку комментария
4. Введите комментарий с формулой: `Формула $E = mc^2$`
5. Нажмите **Enter**
6. ✨ **Формула отрендерится!**

### 2. Включить Track Changes (отслеживание изменений):

1. В правой панели Review
2. Нажмите на переключатель "Track changes"
3. Теперь все изменения будут отслеживаться
4. Можно принимать/отклонять изменения

### 3. Просмотр комментариев:

- **Current File** - комментарии в текущем файле
- **Overview** - все комментарии во всех файлах проекта

## 🎓 ПРИМЕРЫ КОММЕНТАРИЕВ С ФОРМУЛАМИ:

### Простые формулы:
```
Формула Эйнштейна: $E = mc^2$
Квадратный корень: $\sqrt{2}$
Дробь: $\frac{a}{b}$
```

### Сложные формулы:
```
Сумма ряда: $\sum_{i=1}^n i = \frac{n(n+1)}{2}$
Интеграл: $\int_0^\infty e^{-x} dx = 1$
Предел: $\lim_{x \to \infty} \frac{1}{x} = 0$
```

### Display формулы (большие):
```
$$\frac{\partial^2 u}{\partial t^2} = c^2 \nabla^2 u$$

$$\int_0^1 x^2 dx = \frac{1}{3}$$
```
