# Review Panel с поддержкой MathJax

## Описание

В эту кастомную версию Overleaf CE добавлена функция Review (панель рецензирования) с поддержкой рендеринга математических формул через MathJax.

## Функциональность

### Основные возможности:

1. **Добавление комментариев** - пользователи могут выделить текст в редакторе и добавить комментарий
2. **Ответы на комментарии** - другие пользователи могут видеть и отвечать на комментарии
3. **Рендеринг формул через MathJax** - математические формулы в комментариях автоматически рендерятся после отправки

### Как использовать:

1. **Добавить комментарий:**
   - Выделите текст в редакторе
   - Нажмите на кнопку "Comment" или используйте контекстное меню
   - Введите текст комментария
   - Нажмите Enter или кнопку "Comment" для отправки

2. **Математические формулы:**
   - Формулы можно добавлять в стандартной LaTeX нотации
   - Inline формулы: `$E = mc^2$` или `\(E = mc^2\)`
   - Display формулы: `$$\int_0^1 x^2 dx$$` или `\[\int_0^1 x^2 dx\]`
   - После нажатия Enter формулы автоматически рендерятся через MathJax

3. **Примеры формул:**
   ```
   $\alpha + \beta = \gamma$
   $$\sum_{i=1}^n i = \frac{n(n+1)}{2}$$
   \(\lim_{x \to \infty} \frac{1}{x} = 0\)
   \[\int_0^\infty e^{-x} dx = 1\]
   ```

## Технические детали

### Измененные файлы:

1. **`services/web/frontend/js/features/review-panel/components/review-panel-comment-with-math.tsx`**
   - Новый компонент для рендеринга комментариев с MathJax
   - Объединяет функциональность ExpandableContent с MathJax рендерингом
   - Поддерживает Linkify для автоматического создания ссылок

2. **`services/web/frontend/js/features/review-panel/components/review-panel-message.tsx`**
   - Обновлен для использования нового компонента ReviewPanelCommentWithMath
   - Заменен импорт ExpandableContent на ReviewPanelCommentWithMath

3. **`services/web/frontend/stylesheets/pages/editor/review-panel.scss`**
   - Добавлены стили для MathJax контейнеров внутри комментариев
   - Улучшена стилизация ссылок в комментариях

### Как это работает:

1. Компонент `ReviewPanelCommentWithMath` отслеживает содержимое комментария через `useEffect`
2. После монтирования или изменения содержимого вызывается `loadMathJax()`
3. MathJax сканирует DOM элемент и рендерит все найденные математические формулы
4. Результат отображается в виде SVG графики прямо в комментарии

### Зависимости:

- MathJax (уже встроен в Overleaf)
- React Linkify (уже используется в chat компоненте)
- Существующая инфраструктура review panel

## Преимущества по сравнению с обычным Overleaf:

В отличие от стандартного Overleaf, где комментарии отображают формулы как обычный текст, в этой версии:
- Формулы автоматически рендерятся и отображаются в читаемом виде
- Улучшенная читабельность технических комментариев
- Единообразный стиль с основным редактором

## Тестирование:

Для тестирования функциональности:
1. Откройте проект в Overleaf
2. Выделите текст и добавьте комментарий с формулой, например: `Здесь должно быть $E = mc^2$`
3. Нажмите Enter
4. Формула должна отрендериться и отобразиться в правильном математическом формате
5. Другие пользователи должны видеть отрендеренную формулу

## Примечания:

- MathJax загружается асинхронно, поэтому может быть небольшая задержка перед рендерингом
- Формулы сохраняются в исходном LaTeX виде в базе данных
- Рендеринг происходит на клиентской стороне
