# Настройка почтового сервера для разработки

## Быстрый старт

```bash
./start-mail.sh
```

После запуска:
- **Overleaf**: http://localhost
- **Mailpit (веб-интерфейс)**: http://localhost:8025

При регистрации нового пользователя письмо с подтверждением появится в Mailpit.

## Чтение писем

### В браузере
Откройте http://localhost:8025 — увидите все письма с удобным интерфейсом.

### Программно (Python)
```bash
python3 read-emails.py
```

### Через API
```bash
# Список всех писем
curl http://localhost:8025/api/v1/messages

# Конкретное письмо
curl http://localhost:8025/api/v1/message/{ID}
```

## Что настроено

- **Mailpit** — SMTP сервер на порту 1025
- **Web UI** — интерфейс на http://localhost:8025
- **EMAIL_CONFIRMATION_DISABLED=false** — включено подтверждение email
- **Кастомный settings.dev.js** — настройки SMTP для development

## Остановка

```bash
cd develop
./bin/down
```
