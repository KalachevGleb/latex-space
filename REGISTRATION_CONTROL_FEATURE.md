# Управление регистрацией пользователей

## Описание

Добавлена возможность управления регистрацией новых пользователей через админ-панель. По умолчанию регистрация **выключена**, и только администраторы могут создавать новые учётные записи.

## Как использовать

### 1. Доступ к настройке

1. Войдите в систему как администратор
2. Перейдите на страницу админ-панели: `http://localhost/admin`
3. Откройте вкладку **"Registration Settings"**

### 2. Управление регистрацией

На вкладке "Registration Settings" вы увидите:

- **Checkbox "Allow users to register new accounts"** - включает/выключает возможность самостоятельной регистрации
- Индикатор текущего состояния (включена/выключена регистрация)

#### Включение регистрации

1. Установите галочку "Allow users to register new accounts"
2. Настройка сохранится автоматически
3. Пользователи смогут регистрироваться через страницу `/register`

#### Выключение регистрации

1. Снимите галочку "Allow users to register new accounts"
2. Настройка сохранится автоматически
3. При попытке доступа к `/register` неавторизованные пользователи увидят сообщение об ошибке
4. Администраторы по-прежнему смогут создавать пользователей через `/admin/register`

## Технические детали

### Компоненты

1. **Модель данных**: `SystemSettings` - хранит настройки в MongoDB
2. **Менеджер**: `SystemSettingsManager` - управляет чтением/записью настроек
3. **Middleware**: `SystemSettingsMiddleware` - проверяет доступ к странице регистрации
4. **Контроллер**: `AdminController.toggleRegistration` - обрабатывает изменение настройки
5. **UI**: Обновлённая админ-панель с новой вкладкой

### API Endpoint

```
POST /admin/registration/toggle
Body: { enabled: true/false }
```

### База данных

Настройка хранится в коллекции `systemSettings`:

```javascript
{
  key: 'registrationEnabled',
  value: true/false,
  createdAt: Date,
  updatedAt: Date
}
```

### Значение по умолчанию

По умолчанию `registrationEnabled = false` (регистрация выключена)

## Примечания

- Администраторы всегда имеют доступ к странице регистрации, независимо от настройки
- Настройка применяется немедленно, перезапуск сервера не требуется
- При ошибке чтения настройки из БД используется значение по умолчанию (fail-safe)
