# Обновление переводов русского языка в Overleaf

## Обзор проделанной работы

Было добавлено **546 новых переводов** для русского языка, что увеличило общее количество переводов с 480 до 1026. Также были удалены дублирующиеся ключи переводов, добавлены недостающие ключи для admin-меню в английскую локализацию, и полностью переведена страница регистрации пользователей в админ-панели.

## Технические изменения

### Файлы, измененные:
1. **`/services/web/locales/ru.json`** - Добавлено 174 новых перевода
2. **`/services/web/app/views/admin/index.pug`** - Обновлены переводы для админ-панели
3. **`/services/web/frontend/js/features/settings/components/interface-language-section.tsx`** - Исправлен код для поддержки переводов

### Ключевые исправления:
1. Добавлена поддержка всех доступных языков в `Translations.js`
2. Обновлен middleware для применения пользовательских настроек языка
3. Исправлены переводы в админ-панели
4. Добавлены переводы для всех основных элементов интерфейса
5. Удалены дублирующиеся ключи переводов для предотвращения конфликтов
