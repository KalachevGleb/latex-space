# Как увидеть изменения в dev режиме

## ✅ Webpack успешно перезапущен!

Компиляция завершена успешно. Теперь выполните следующие шаги:

## 1. Обновите браузер с очисткой кэша

### На Mac:
```
⌘ Cmd + ⇧ Shift + R
```

### На Windows/Linux:
```
Ctrl + Shift + R
```

### Альтернативно:
1. Откройте DevTools (F12)
2. Правый клик на кнопке обновления в браузере
3. Выберите "Очистить кэш и жёсткая перезагрузка"

## 2. Если изменения всё ещё не видны:

### Полная очистка кэша браузера:
1. Откройте настройки браузера
2. Найдите "Очистить данные браузера" / "Clear browsing data"
3. Выберите "Кэшированные изображения и файлы"
4. Очистите за "Всё время"
5. Обновите страницу

## 3. Проверка работы Review Panel:

1. **Откройте проект** в Overleaf
2. **Выделите текст** в редакторе
3. **Нажмите на иконку комментария** (справа должна появиться панель)
4. **Введите комментарий** с формулой:
   ```
   Проверьте формулу $E = mc^2$
   ```
5. **Нажмите Enter** - формула должна отрендериться!

## 4. Автоматическая перезагрузка в будущем

Webpack dev server настроен на автоматическую перекомпиляцию при изменении файлов. 

**Для будущих изменений:**
- Просто редактируйте файлы в `services/web/frontend/`
- Webpack автоматически перекомпилирует (займет ~30-60 сек)
- Обновите браузер (Cmd+Shift+R)

**Если изменения не подхватываются:**
```bash
cd /Users/gleb/Projects/overleaf/develop
docker-compose restart webpack
# Подождите ~60 секунд для компиляции
```

## 5. Полезные команды для разработки

### Посмотреть логи webpack:
```bash
cd /Users/gleb/Projects/overleaf/develop
docker-compose logs -f webpack
```

### Посмотреть логи web сервера:
```bash
docker-compose logs -f web
```

### Проверить статус всех контейнеров:
```bash
docker-compose ps
```

### Перезапустить всё (если что-то сломалось):
```bash
bin/down
bin/dev
```

## 6. Где находятся изменения

### Новый компонент:
```
services/web/frontend/js/features/review-panel/components/
└── review-panel-comment-with-math.tsx
```

### Измененные файлы:
```
services/web/frontend/js/features/review-panel/components/
└── review-panel-message.tsx

services/web/frontend/stylesheets/pages/editor/
└── review-panel.scss
```

## 7. Отладка в браузере

1. Откройте DevTools (F12)
2. Перейдите на вкладку Console
3. Проверьте, нет ли ошибок JavaScript
4. В Network проверьте, что файлы загружаются с webpack dev server

## 🎉 Готово!

После очистки кэша браузера вы должны увидеть работающую функцию Review с рендерингом формул через MathJax!

---

**Важно:** Dev режим с hot reload работает только для JavaScript/TypeScript файлов. 
Если вы редактируете SCSS файлы, может потребоваться полная перезагрузка страницы.
