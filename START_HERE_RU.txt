📋 ЧТО НУЖНО СДЕЛАТЬ ДАЛЬШЕ:

  ⚠️  ГЛАВНОЕ: Установить Docker Desktop
  
  Способ 1 (рекомендуется):
    → Откройте https://www.docker.com/products/docker-desktop
    → Скачайте Docker Desktop for Mac
    → Установите и запустите
  
  Способ 2 (через Homebrew):
    → brew install --cask docker
    → Запустите Docker Desktop из Applications
    → Дождитесь полного запуска Docker

🚀 ПОСЛЕ УСТАНОВКИ DOCKER:

  1. Проверьте готовность системы:
     cd /Users/gleb/Projects/overleaf
     ./check-ready.sh
  
  2. Запустите автоматическую настройку:
     ./setup.sh
  
  3. Запустите Overleaf:
     cd develop
     ./bin/dev
  
  4. Откройте браузер:
     http://localhost/launchpad

🛠️ ПОЛЕЗНЫЕ СКРИПТЫ:

  ./check-ready.sh   → Проверка готовности системы
  ./setup.sh         → Автоматическая настройка
  develop/bin/dev    → Запуск в режиме разработки
  develop/bin/up     → Обычный запуск
  develop/bin/down   → Остановка
  develop/bin/logs   → Просмотр логов

🔥 КАК РАБОТАЕТ LIVE-RELOAD:

  Frontend (React):
    • Путь: services/web/frontend/
    • Изменения видны МГНОВЕННО без перезагрузки браузера
    • Hot Module Replacement включен
  
  Backend (Node.js):
    • Путь: services/web/app/
    • Сервис автоматически перезапускается при изменениях
    • Требуется обновление страницы в браузере
    • Перезапуск занимает 1-3 секунды

🎯 БЫСТРЫЙ СТАРТ (после установки Docker):

  cd /Users/gleb/Projects/overleaf
  ./setup.sh
  cd develop
  ./bin/dev web webpack
  
  → Откройте: http://localhost/launchpad

💡 СОВЕТЫ:

  • Для быстрой работы запускайте только нужные сервисы:
    ./bin/dev web webpack
  
  • TeX Live образ можно собрать позже (занимает 1-2 часа):
    docker build texlive -t texlive-full
  
  • Используйте Chrome DevTools для отладки:
    chrome://inspect → localhost:9229
