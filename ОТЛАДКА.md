# 🔧 Отладка Review Panel с MathJax в dev режиме

## ✅ Быстрая проверка

### Проверьте, что всё запущено:
```bash
cd /Users/gleb/Projects/overleaf/develop
docker-compose ps
```

Должны быть "Up":
- ✅ `develop-webpack-1` (порт 127.0.0.1:80->3808/tcp)
- ✅ `develop-web-1` (порт 127.0.0.1:9229->9229/tcp)
- ✅ `develop-mongo-1`
- ✅ `develop-redis-1`

## 🔍 Если изменения не видны

### 1. Очистите кэш браузера
**Важно:** Обычное обновление (F5) НЕ работает!

**Mac:**
```
⌘ Cmd + ⇧ Shift + R
```

**Windows/Linux:**
```
Ctrl + Shift + R
```

**Или через DevTools:**
1. F12
2. Network tab → ✅ Disable cache
3. Правый клик на кнопке обновления → "Очистить кэш и жёсткая перезагрузка"

### 2. Проверьте логи webpack
```bash
cd /Users/gleb/Projects/overleaf/develop
docker-compose logs webpack --tail=50
```

Должно быть:
```
webpack 5.98.0 compiled successfully in XXXXX ms
```

**Если видите ошибки компиляции:**
- Проверьте синтаксис в файлах TypeScript
- Убедитесь, что все импорты правильные

### 3. Перезапустите webpack
```bash
cd /Users/gleb/Projects/overleaf/develop
docker-compose restart webpack
```

Подождите 60 секунд для компиляции:
```bash
sleep 60 && docker-compose logs webpack --tail=20
```

### 4. Проверьте, что файлы видны в контейнере
```bash
docker-compose exec webpack ls -la /overleaf/services/web/frontend/js/features/review-panel/components/ | grep review-panel-comment-with-math
```

Должен быть файл:
```
review-panel-comment-with-math.tsx
```

## 🚨 Если webpack не компилируется

### Проверьте логи на ошибки:
```bash
docker-compose logs webpack 2>&1 | grep -i error
```

### Общие проблемы:

**Ошибка: "Module not found"**
```bash
# Проверьте импорты в файле
cat services/web/frontend/js/features/review-panel/components/review-panel-comment-with-math.tsx | head -10
```

**Ошибка: TypeScript compilation**
```bash
# Проверьте типы
cd /Users/gleb/Projects/overleaf
npm run types:check
```

### Полная перезагрузка webpack:
```bash
cd /Users/gleb/Projects/overleaf/develop
docker-compose stop webpack
docker-compose rm -f webpack
bin/dev webpack
```

## 🌐 Если браузер показывает старую версию

### Проверьте в браузере:
1. F12 → Console
2. Есть ли ошибки JavaScript?
3. Network tab → проверьте откуда загружаются файлы

**Должно быть:**
- JS файлы загружаются с `localhost` или `127.0.0.1`
- Status 200 (не 304!)

### Полная очистка кэша браузера:
1. Настройки → Конфиденциальность
2. Очистить данные браузера
3. ✅ Кэшированные изображения и файлы
4. За "Всё время"
5. Очистить

### Проверьте, что webpack dev server отвечает:
```bash
curl -s http://localhost/manifest.json | head -5
```

Должен вернуть JSON с файлами.

## 🐛 Если функция Review не работает

### Проверьте права доступа:
1. Откройте проект
2. Settings → Permissions
3. Убедитесь, что у вас есть права на комментирование

### Проверьте, что trackChanges включен:
```bash
docker-compose logs web 2>&1 | grep -i "track"
```

### Проверьте JavaScript ошибки:
1. F12 → Console
2. Есть ли ошибки при добавлении комментария?

**Частые ошибки:**
- `MathJax is not defined` → MathJax не загрузился
- `loadMathJax is not a function` → проблема с импортом
- `ReviewPanelCommentWithMath is not defined` → webpack не подхватил файл
